# Frozen-result figure layer

The scientific question is whether whole-brain infection-associated expression and selected-transcript agreement are reconstructed at 11 and 33 days. The observed unit is a reported biological library: three controls and three infected libraries per time point. Different animals were sampled across times. The pooling ambiguity and unavailable batch/cage assignments remain unresolved. This layer succeeds when every plotted value can be matched to a frozen table, selection thresholds and conditional denominators are unchanged, and all outputs are readable and reproducible.

Run `bash scripts/figures/build_all.sh` from the repository root with R and Python on PATH. This runs only deterministic plotting, vector export, report composition and validation. The saved sample coordinates, distance matrices, row Z scores, differential-expression results, GO tables and publication-comparison tables are the inputs. No FASTQ, quantification, normalization, PCA refit, DESeq2 fit, enrichment test or new hypothesis test is performed.

R dependencies: ggplot2 4.0.3, patchwork 1.3.2 and ggrepel (exact version in `report/figures/redesigned/session-info.txt`). Python versions are pinned in `requirements.txt`; tested runtime details are in `environment-versions.json`. Existing analysis-container locks are unchanged. `design-config.json` documents the plotting configuration; the executable R constants implement it. The script checks the stored alpha and fold-change cutoff against those constants.

Outputs are deterministic paths in `report/figures/redesigned/`. The build replaces only this derived figure directory and `report/report.pdf`; original `docs/figures`, analysis figures, presentation figures and scientific result tables remain recoverable in place. `figure-manifest.tsv` maps every final figure to inputs and derived plotting tables. Quoted TSV fields preserve multiline labels. The manifest includes the retained workflow schematic separately from scientific observations.

R's native PDF device emits vector geometry and text. PyMuPDF exports SVG with `text_as_path=True` and 360-dpi PNG from the same PDF canvas. SVG labels use vector glyph outlines for portable placement: the text-preserving export uses per-character x-coordinate lists that the inspection renderer did not support. PDF labels remain searchable text. Continuous legends use vector rectangles. The native Cairo device was unavailable in this host's R installation because X11 libraries were absent; this export route avoids changes to the host or analysis environment. PDF text uses standard Helvetica/sans-serif families; SVG glyph outlines and raster exports fix the exact appearance. The report embeds the PDF artwork through pypdf transformations without rasterization. The retained workflow is drawn directly in ReportLab and receives padding only in its standalone export.

In this publication candidate, two large SVGs are supplied in a separate [vector attachment](../../docs/RELEASE_ASSETS.md). Before validating the saved figure collection, restore those files to their original paths. A complete build regenerates them; their exact paths are Git-ignored to keep the attachment out of ordinary history. Historical figure mappings describe the complete restored collection.

Validation: `python scripts/figures/validate_redesign.py` verifies hashes, stable-key alignment, transformations, counts, sample groups, conditional correlations and recovery denominators, all formats, page bounds, vector objects and retained authorship. It writes `docs/figure-redesign/validation.json`; run it in a disposable copy when checking a fixed release. It is not a rerun of the biological analysis. Run the project checks with `python -m unittest discover -s tests -p 'test_*.py'` and `python scripts/check_example_results.py`.

Main-figure typography is sized for the actual A4 report placement: essential labels and legends must be at least 7.5 pt, and supporting notes at least 7 pt. The report builder records its actual affine placements in `docs/figure-redesign/report-placements.json`. The validator measures searchable source-PDF spans, applies those scales, and checks the resulting sizes against the final report spans; `typography.json` records every measured text span. Mathematical subscripts retain relative typesetting while their base axis label must satisfy the essential-label target. These are project QA criteria, not journal specifications. Font-size checks supplement visual review of every final page and regenerated format; they do not detect every possible overlap.
